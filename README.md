# Mobile-IDE
Мобильная среда разработки, создаётся ради возможности локально продолжать разработку с разных устройств. Выполнено сугубо вайбкодингом.
Цель: создать кросплатформенговую систему , включающую себя локальную базу данных, локальное хранилище, возможность пересылки данных через Bluetooth подключение.
